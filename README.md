## Description

**kdeconnect** is a KDE application that enables seamless integration between your Linux desktop and Android devices. It allows you to share files, receive notifications, control media playback, use your phone as a remote input device, and much more — all over the local network.

## About This Package

This is an **Aurelis Linux** package built as an AppImage. It can also run as a regular AppImage on any Linux distribution without installation.
